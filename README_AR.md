# HUAWEI SALES ELITE — مشروع Flutter

هذا **كود مصدر لتطبيق جوال** يعمل على Android وiPhone بعد البناء والتوقيع، وليس APK/IPA جاهزًا.

## المحتويات
- تسجيل الموظف: الاسم واسم المعرض.
- ٣٠ يومًا × ٣ مهام، تتغير بحسب تاريخ السعودية، وتبدأ من يوم تسجيل الموظف.
- ١٢ درسًا بالعربية مع سيناريوهات وردود وتدريبات.
- نقاط الموظف: ٣٠ نقطة لكل مهمة و٥٠ نقطة لكل درس.
- لوحة مسؤول محمية بكلمة مرور مخزنة كـ hash في قاعدة البيانات.
- مزامنة إنجازات الموظفين إلى Supabase عند توفر الاتصال، وحفظ محلي عند عدم توفره.
- الهوية باللونين الأسود والذهبي، وعناوين الواجهة بالعربية باستثناء اسم التطبيق والسطرين الإنجليزيين تحته.

## تشغيل المشروع
1. ثبّت Flutter وAndroid Studio وXcode (لبناء iOS تحتاج جهاز macOS وحساب Apple Developer للتوزيع).
2. نفّذ `flutter create --platforms=android,ios .` من داخل المجلد لإنشاء ملفات المنصتين القياسية.
3. نفّذ `flutter pub get`.
4. أنشئ مشروع Supabase، وفعّل **Anonymous Sign-ins** في إعدادات Authentication.
5. نفّذ `supabase/schema.sql` داخل SQL Editor. رمز المسؤول الأولي المحدد محفوظ في SQL كقيمة تهيئة ويُحوّل إلى hash عند التشغيل؛ **غيّره قبل النشر** ولا تشارك ملف SQL مع الموظفين.
6. نفّذ:
   `flutter run --dart-define=SUPABASE_URL=YOUR_URL --dart-define=SUPABASE_ANON_KEY=YOUR_PUBLISHABLE_KEY`
7. بناء Android: `flutter build apk --release --dart-define=SUPABASE_URL=YOUR_URL --dart-define=SUPABASE_ANON_KEY=YOUR_PUBLISHABLE_KEY`.
8. بناء iPhone عبر macOS وXcode، وتوزيعه عبر TestFlight بعد التوقيع.

## تنبيهات مهمة قبل توزيع التطبيق
- المشروع **لم يُبنَ أو يُختبر فعليًا** هنا لعدم توفر Flutter/Android SDK/Xcode في بيئة العمل.
- لوحة المسؤول لا تعمل دون إعداد Supabase، والمزامنة تتطلب اتصال إنترنت. البيانات المحلية قد تضيع عند حذف التطبيق.
- التسجيل بالاسم والمعرض فقط لا يتحقق من هوية الموظف؛ يستطيع الشخص إعادة التسجيل أو تغيير الجهاز. يلزم نظام تحقق أقوى إذا كانت النقاط تستخدم في تقييم رسمي أو جوائز.
- دخول المسؤول يحتاج تحديد عدد المحاولات (rate limiting) ومراقبة أمنية قبل النشر؛ التحقق من كلمة المرور موجود في قاعدة البيانات وليس في التطبيق.
- بعد اليوم ٣٠ تبقى مهام اليوم ٣٠؛ يمكن تطوير دورة ثانية لاحقًا.
- أي نشر يحمل علامة HUAWEI رسميًا يستلزم إذنًا من صاحب العلامة.
